Questions

Does it add virtual audio devices?

No. It works with the outputs you already have. For a separate stream mix, install a virtual cable such as VB-Cable and Divisi shows it as an output.

Does it work with OBS and Discord?

Yes. Leave their output on Default and Divisi routes them like any other app. An app set to a specific device in its own settings plays there whatever Divisi does.

Will it slow my games down?

An app on one output uses Windows' own routing, so it costs nothing. An app on several outputs goes through Divisi's engine, which uses about 1.6 ms of CPU per second and adds 4 to 20 ms of delay.

What about fullscreen games?

Borderless and windowed games work as normal: the quick mixer opens over them. In exclusive fullscreen the hotkey does nothing, so your game isn't minimized.

What if Divisi crashes?

A watchdog puts back everything Divisi changed. If both stop at once, say in a power cut, Divisi restores everything first the next time it starts.

Which Windows versions does it run on?

Windows 11.
